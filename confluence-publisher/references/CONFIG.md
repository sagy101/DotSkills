# Configuration Reference

The `.confluence.json` file lives in the project root and configures the publisher for that project.

## Full schema

```json
{
  "confluence_url": "https://mycompany.atlassian.net/wiki",
  "space_key": "DOCS",
  "root_page_id": "123456",
  "docs_dir": ".",
  "manifest_path": ".confluence-manifest.json",
  "credentials": {
    "username_env": "CONFLUENCE_EMAIL",
    "token_env": "CONFLUENCE_TOKEN"
  },
  "env_file": ".env",
  "title_map": {
    "README.md": "My Project Home",
    "plan/README.md": "Design & Plan"
  },
  "exclude_patterns": [
    "node_modules/**",
    ".git/**",
    "vendor/**"
  ]
}
```

## Field descriptions

| Field | Required | Default | Description |
|---|---|---|---|
| `confluence_url` | Yes | — | Base URL of your Confluence Cloud instance (include `/wiki`) |
| `space_key` | Yes | — | Confluence space key where pages live |
| `root_page_id` | Yes | — | ID of the root page under which all docs are published |
| `docs_dir` | No | `"."` | Directory containing markdown files, relative to project root |
| `manifest_path` | No | `".confluence-manifest.json"` | Where to store the manifest file |
| `credentials.username_env` | No | `"CONFLUENCE_EMAIL"` | Environment variable name for the Atlassian username/email |
| `credentials.token_env` | No | `"CONFLUENCE_TOKEN"` | Environment variable name for the API token |
| `env_file` | No | `null` | Optional path to a `.env` file to load credentials from |
| `title_map` | No | `{}` | Override titles for specific files. If not specified, titles are derived from the first `# heading` in the markdown file, or from the filename |
| `exclude_patterns` | No | `[]` | Glob patterns for files/directories to skip when scanning for markdown files |

## Credential resolution order

1. If `env_file` is set, load variables from that file first
2. Then check OS environment variables
3. The variable names are taken from `credentials.username_env` and `credentials.token_env`

## Title resolution order

1. Explicit entry in `title_map`
2. First `# heading` in the markdown file
3. Filename without extension, title-cased (e.g. `my-design.md` → `My Design`)

## Manifest format

The manifest (`.confluence-manifest.json`) is auto-generated and maps relative file paths to Confluence page metadata:

```json
{
  "README.md": {
    "id": "123456",
    "title": "My Project Home",
    "parent_id": null,
    "last_published": "2025-02-20T10:30:00Z"
  },
  "plan/README.md": {
    "id": "123457",
    "title": "Design & Plan",
    "parent_id": "123456",
    "last_published": "2025-02-20T10:30:05Z"
  }
}
```

Do not edit this file manually — the scripts maintain it automatically.
